# physics-math 
这是一个分享数学和物理研究生的科研笔记的地方，欢迎加入我们，发起人邮箱 1294178715@qq.com
## 格式
1. 仓库分为物理和数学两个大分类，可以在下面创建自己的子分类并上传笔记
2. 每份笔记需要单独创建一个文件夹，文件夹后缀要有提交者自己的标记字符（不要与其他提交者重复），例如我的后缀是 `att`，我建的一个文件夹是
   `局域视界-att`
3. 起了自己的专属标记字符后，请在本readme的后面补充，方便其他人参考、查阅
4. 创建笔记文件夹后可以在文件夹下上传笔记本体，格式不做硬性要求，建议上传一份md或者tex的源码后再上传一份pdf文件阅读使用
5. 可以参考已经有的笔记文件夹格式
## 注意
1. 请大家尽量**按照格式**上传笔记，共同维护仓库的整洁，方便大家快速检索、定位
2. 由于后缀的存在，不同的作者可以上传同名笔记，但是请避免创建重复或相近的分支，而是把重名笔记提交到已有分支下
3. 如有必要，一篇笔记可以放在多个分支下
## 标记字符

2. `owl`
3. `zhm`
4. `zf`

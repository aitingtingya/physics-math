# 代数拓扑
## 同调群
### 阿贝尔群
 Def $\mathbb{Z}_{k}:=\mathbb{Z}/k\mathbb{Z}$
 Def 如果$G$由$r$个线性无关的元素生成，则称$G$为一个秩为$r$的自由阿贝尔群。若$r\in{}\mathbb{Z}$，则称为有限生成的。
 Remark 任意两个循环群的直积群都是非自由的，例如$\mathbb{Z}_{p_{1}}\times{}\mathbb{Z}_{p_{2}}$，设它们的生成元为$x$和$y$，则有$p_{1}x+p_{2}y=0$
 Def 如果$G$的秩为一，则称其为循环群，根据$o(G)$是否有限分为无限循环群和有限循环群。（与有限/无限生成不一样）
 Thm 无限循环群都同构于$\mathbb{Z}$，有限循环群$G$同构于$\mathbb{Z}_{o(G)}$。
 Lemma $G$是秩为$r$的自由阿贝尔群，$H$是其非空子群，则$H$同构于$k_{1}\mathbb{Z}+k_{2}\mathbb{Z}+...+k_{p}\mathbb{Z}$。
 Prove 
$设x_{1}...x_{r}是群G的生成元$，$则能找到一组整数\{k_{i}\}使得k_{1}x...k_{p}x是H的生成元$，$得证$。
 Thm 循环群G有$m$个生成元，则存在某个数$r$使其同构于$\mathbb{Z}\times{}_{1}...\times{}_{r-1}\mathbb{Z}\times{}\mathbb{Z}_{k_{1}}\times{}_{r}...\times{}_{m-1}\mathbb{Z}$。
 Prove 
$设f:\mathbb{Z}^{m}\rightarrow{}G$，$则G同构于\mathbb{Z}^{m}/ker(f)$，$由于ker(f)是自由阿贝尔群\mathbb{Z}^{m}的一个子群$，$存在n个数使得ker(f)同构于k_{1}\mathbb{Z}\oplus...\oplus k_{n}\mathbb{Z}$，从而得证。
### 单形和单纯复型
 Def $\mathbb{R}^{m}$维空间中的$r(m\geq{}r)$个点称为几何独立的如果不存在$r-2$维的超平面包括所有的点。
 Def $\mathbb{R}^{m}$上由$r+1(m\geq{}r)$个点生成的$r-$单形$\sigma{}^{r}=\langle p_{0},...p_{r}\rangle$定义为$\sigma{}^{r}:=\{x\in{}\mathbb{R}^{m}|x=c^{i}r_{i},c^{i}\geq{}0,\sum\limits_{i}^{}c^{i}=1\}$。称$(c^{0},...,c^{r})$为$x$的质心坐标。
 Thm $\sigma{}^{r}$是紧的有界闭集。
 Def 由$\sigma{}^{r}$中$q+1\leq{}r+1$个子点集生成的$q-$单形$\sigma{}^{q}$称为$\sigma{}^{r}$的一个$q-$面，记作$\sigma{}^{q}\leq{}\sigma{}^{r}$，特别的如果$q\neq r$，称其为真面，记作$\sigma{}^{q}<\sigma{}^{r}$。
 Thm 一个$r-$单形有$C^{q+1}_{r+1}$个$q-$面。
 Def 称单形集$K$中的元素是恰当拼合的，如果
1. $\forall{}\sigma{}\in{}K$，$\sigma{}'\leq{}\sigma{}\rightarrow{}\sigma{}'\in{}K$;
2. $\forall{}\sigma{},\sigma{}'\in{}K$，$\sigma{}\cap_{}^{}\sigma{}'\neq\emptyset\rightarrow{}\sigma{}\cap_{}^{}\sigma{}'\leq{}\sigma{}$
 此时称$K$为单纯复形。
 Def 定义单纯复形的维数为其元素的最大维数。
 Def 单纯复形$K$中所有元素作为集合的并集$|K|$称为$K$的多面体。
 Def 设$X$是一个拓扑空间，如果$\exists{}K$是单纯复形和映射$f:|K|\rightarrow{}X$是一个同胚，则称$X$为可三角剖分的，$(K,f)$称为$X$的一个三角剖分。

 Def 对于一个$r-$单形$\sigma{}^{r}=\langle p_{0}...p_{r}\rangle$，定义一个双射$o:\{0,1,,,r\}\rightarrow{}\{p_{0},...,p_{r}\}$称为给$\sigma{}_{r}$指定一个定向，配以定向$o$的$\sigma{}_{r}$记作$(o(0),o(1),...,o(r))$。
 Def 赋予同一单形的不同定向以加法结构：
$$
\begin{eqnarray}
(p_{i_{0}}...p_{ir})={\rm sgn}\begin{pmatrix}
0&1&...&r \\
p_{i_{0}}&p_{i_{1}}&...&p_{ir}
\end{pmatrix}(p_{0}...p_{r})
\end{eqnarray}
$$
### 同调群
 Def 单复形$K$的一个$r-$链群$C_{r}(K)$定义为一个由$K$中的全体定向$r-$单形生成的自由阿贝尔群。如果$r>K$，则将其定义为平凡群。称$C_{r}(K)$中的元素为$r-$链。
 Def 设$\sigma{}_{r}\in{}K$，定义$K$单形的边界算符为线性算符$\partial{}_{r}:C_{r}(K)\rightarrow{}C_{r-1}(K)$,$\sigma{}_{r}\mapsto{}\sum\limits_{i}^{}(-1)^{i}(p_{0},...,p_{i-1}p_{i+1},...,p_{r})$，特别的$\partial{}_{0}\sigma{}_{0}=0$。
 Def 称一个单复形$K$是连通的，如果$\forall{}p_{0},p_{n}\in{}K$，$\exists{}(p_{0},p_{ 1}),(p_{1},p_{2}),...,(p_{n-1},p_{n})\in{}K$满足$\partial{}_{1}[(p_{0},p_{ 1})+(p_{1},p_{2})+...+(p_{n-1},p_{n})]=p_{n}-p_{0}$。
 Remark 对$0$的作用可以用任意一对互逆元素来得到。
 Thm $\partial{}_{r}$是一个群同态。
 Def 如果$c\in{}C_{r}(K)$满足$\partial{}_{r}c=0$，则称其为一个$r-$循环。
 Thm $C_{r}(K)$的所有$r-$循环的集合$Z_{r}(K)$是一个子群称为$r-$循环群。
 Def $c\in{}C_{r}(K)$，如果$\exists{}d\in{}C_{r+1}(K),\partial{}_{r+1}d=c$，则称$c$为一个$r-$边界。
 Thm $C_{r}(K)$的所有$r-$边界的集合$B_{r}(K)$是一个子群称为$r-$边界群。
 Lemma $\partial{}_{r}\circ{}\partial{}_{r+1}=0$
 Prove 
$$
\begin{eqnarray}
&&\partial{}_{r}\partial{}_{r+1}\sigma{}_{r+1}\\
&=&\partial{}_{r}\sum\limits_{i}^{}(-1)^{i}(p_{0},...,p_{i-1}p_{i+1},...,p_{r+1})\\
&=&\sum\limits_{i}^{}(-1)^{i}[\sum\limits_{j=0}^{i-1}(-1)^{j}(p_{0},...,\hat{p}_{j},...,\hat{p}_{i},...,p_{r+1})+\sum\limits_{j=i+1}^{j+1}(-1)^{j-1}(p_{0},...,\hat{p}_{i},...,\hat{p}_{j},...,p_{r+1})]\\
&=&\sum\limits_{i=0}^{r+1}(-1)^{i}\sum\limits_{j=0}^{i-1}(-1)^{j}(p_{0},...,\hat{p}_{j},...,\hat{p}_{i},...,p_{r+1})+\sum\limits_{j=1}^{r+1}(-1)^{j-1}\sum\limits_{i=0}^{j-1}(-1)^{i}(p_{0},...,\hat{p}_{i},...,\hat{p}_{j},...,p_{r+1})\\
&=&\sum\limits_{i=1}^{r+1}(-1)^{i}\sum\limits_{j=0}^{i-1}(-1)^{j}(p_{0},...,\hat{p}_{j},...,\hat{p}_{i},...,p_{r+1})+\sum\limits_{i=1}^{r+1}(-1)^{i-1}\sum\limits_{i=0}^{i-1}(-1)^{j}(p_{0},...,\hat{p}_{j},...,\hat{p}_{i},...,p_{r+1})\\
&=&0
\end{eqnarray}
$$
 Thm $B_{r}(K)\subset{}Z_{r}(K)$
 Def 定义单纯复型$K$的第$r$个同调群$H_{r}(K):=Z_{r}(K)/B_{r}(K)$，称$H_{r}(K)$中的元素为同调类，若$z'\in{}[z]$，则称它们互相同调。
 Prop 任何边界同调于$0$。
 Prove 
$\forall{}b\in{}B_{r}(Z)$，$b-0=b\in{}B_{r}(Z)$。
 Thm 同调群是拓扑不变的，也就是如果$X$同胚于$Y$，$(K,f)$和$(L,g)$分别是$X$和$Y$的三角剖分，则$H_{r}(K)$同构于$H_{r}(L)$。（反过来不一定）
 Def 任取一个拓扑空间$X$的三角剖分$(K,f)$，定义$X$的同调群$H_{r}(X):=H_{r}(K)$。
 Thm 设$K$是连通单纯复形，则$H_{0}(K)$同构于$\mathbb{Z}$。
 Thm 设$K=K_{1}\cup^{}_{}K_{2}...\cup^{}_{}K_{N},N\in{}\mathbb{Z}^{+},i \neq j\rightarrow{}K_{i}\cap_{}^{}K_{j}=\emptyset$，则$H_{r}(K)=\mathop{\oplus}\limits_{i=1}^{N}H_{r}(K_{i})$。
 Cor 对于上面的$K$，有$H_{0}(K)$同构于$\mathbb{Z}^{N}$。
 Thm $H_{r}(K)$的一般形式为$\mathbb{Z}^{f}\oplus\mathbb{Z}_{k_{1}}\oplus...\oplus\mathbb{Z}_{k_{p}}$
 Prove 
它是自由贝尔群$Z_{r}(K)$模掉自由阿贝尔群$B_{r}(K)$，所以根据阿贝尔群里的结论，自然是这样的结构。
 Def $H_{r}(K)$的非自由部分称为它的扭转子群。
 Def 对于秩为$f$的同调群$H_{r}(K)$，定义$H_{r}(K;\mathbb{R}):=\mathbb{R}^{f}$，同时原本的同调群记作$H_{r}(K;\mathbb{Z})$。
 Def 单纯复形$K$的第$r$个贝蒂数定义为$b_{r}(K):={\rm rank}H_{r}(K,\mathbb{Z})$。
 Thm（欧拉-庞加莱定理）设$K$是一个$n$维单纯复形，$I_{r}$是它的$r-$单形的个数，则$\chi{}(K)\equiv{}\sum\limits_{r=0}^{n}(-1)^{r}I_{r}=\sum\limits_{r=0}^{n}(-1)^{r}b_{r}(K)$。
## 同伦群
### 基本群
 Def 设$X$是一个拓扑空间，$I=[0,1]$，称连续映射$\alpha{}:I\rightarrow{}X$为以$x_{0}=\alpha{}(0)$为起点，$x_{1}=\alpha{}(1)$为终点的一条路径。如果$\alpha{}(0)=\alpha{}(1)$，称这条路径为以$x_{0}$为基点的圈。$X$上的路径集合记作$\mathscr{P}(X)$，以$x$为基点的圈的集合记作$\mathscr{O}_{x}(X)$
 Def 若$\alpha{}\in{}\mathscr{P}(X),\alpha{}[I]=\{x_{0}\}$，则称$\alpha{}$为常路径。
 Def 设$\alpha{},\beta{}\in{}\mathscr{P}(X)$且$\alpha{}(1)=\beta{}(0)$，则定义乘法$*:\mathscr{P}(X)\times{}\mathscr{P}(X)\rightarrow{}\mathscr{P}(X),(\alpha{},\beta{})\mapsto{}\gamma{}$，当$s<\frac{1}{2}$时，$\gamma{}(s)=\alpha{}(2s)$，$s\geq{}\frac{1}{2}$时，$\gamma{}(s)=\beta{}(2s-1)$。
 Def 定义$\alpha{}\in{}\mathscr{P}(X)$的逆满足$\alpha{}^{-1}(s)=\alpha{}(1-s),s\in{}I$。
 Def 设$\alpha{},\beta{}\in{}\mathscr{O}_{x_{0}}(X)$，称它们两个是同伦的如果$\exists{}F:I\times{}I\rightarrow{}X$满足$F(s,0)=\alpha{}(s),F(s,1)=\beta{}(s),\forall{}s\in{}I,F(0,t)=F(1,t)=x_{0}$。映射$F$称为$\alpha{}$和$\beta{}$间的同伦。
 Thm 同伦关系是等价关系，记作$\alpha{}\sim \beta{}$，和$\alpha{}$同伦等价的圈的集合叫做的同伦类，记作$[\alpha{}]$。
 Def 称$\mathscr{O}_{x_{0}}(X)$按同伦等价类进行的划分叫做$X$在$x_{0}$的基本群，记作$\pi{}_{1}(X,x_{0})$，定义其上的乘法运算$*:\pi{}_{1}(X,x_{0})\rightarrow{}\pi{}_{1}(X,x_{0}),([\alpha{}],[\beta{}])\mapsto{}[\alpha{}*\beta{}]$。
 Thm 基本群以同伦类的乘法称为一个群，单位元是$[c_{x_{0}}]$，逆元是$[\alpha{}^{-1}]$。
 Def 称拓扑空间$X$是弧连通的如果$\forall{}x_{0},x_{1}\in{}X,\exists{}\alpha{}\in{}\mathscr{P}(X)$满足$\alpha{}(0)=x_{0},\alpha{}(1)=x_{1}$。
 Thm 如果拓扑空间$X$是弧连通的，则$\forall{}x_{0},x_{1}\in{}X$，则$\pi{}_{1}(X,x_{0})$同构于$\pi{}_{1}(X,x_{1})$。
 Def 设$f,g:X\rightarrow{}Y$是连续的，如果$\exists{}F:X\times{}I\rightarrow{}Y$是连续的且满足$F(x,0)=f(x),F(x,1)=g(x)$，则称$f$同伦于$g$，记作$f\sim g$，称$F$为$f$和$g$间的同伦。
 Def 设$X,Y$是两个拓扑空间，称它们有相同的同伦型如果$\exists{}f\in{}\mathscr{F}(X,Y),g\in{}\mathscr{F}(Y,X)$满足$f\circ{}g=id_{X},g\circ{}f=id_{Y}$，记作$X\simeq Y$。映射$f$叫做同伦等价，$g$叫做它的逆。
 Thm 两个拓扑空间同胚一定同伦，但是同伦不一定同胚。
 Thm 具有相同的同伦型是一个等价关系。
 Thm 设$f\in{}\mathscr{F}(X,Y)$是一个同伦等价，则$\pi{}_{1}(X,x_{0})\simeq{}\pi{}_{1}(Y,f(x_{0}))$。
 Cor 基本群是拓扑同胚不变的。
 Def 称$R\neq\varnothing{}\subset{}X$是拓扑空间$X$的一个缩回如果$\exists{}f\in{}\mathscr{F}(X,R)$满足$f|_{R}=id_{R}$，称这个$f$为一个缩回。
 Def 称$R\subset{}X$是拓扑空间$X$的一个形变缩回如果$\exists{}f$是与$id_{X}$同伦等价的$X$的一个缩回，且$f[X]=R$。
 Def 如果$\exists{}a\in{}X$是拓扑空间$X$的一个形变缩回，则称$X$是可收缩的，$c_{a}:X\rightarrow{}\{a\}$和$id_{X}$之间的同伦$H$叫做$X$向$a$的收缩。
 Thm 可收缩空间的基本群是平凡的。
 Def 称具有平凡基本群的弧连通空间为单连通的。
### 基本群的性质
 Def 将实空间的环推广到复空间：$S^{1}:=\{z\in{}\mathbb{C}|~|z|=1\}$。
 Thm $S_{1}\simeq\mathbb{R}/2\pi{}\mathbb{Z}$，后者中的元素记作$[x]$。
 Prove 
可以构造映射$p:\mathbb{R}\rightarrow{}\mathbb{C},x\mapsto{}e^{ix}$，则$p[(0,2\pi{}]]=S^{1}$。但是$S^{1}$并不同构于$(0,2\pi{}]$，因为在$S^{1}$中$e^{i0}=e^{i2\pi{}}$，所以无论$\delta{}$取多小，可以有一个开集$(1-\delta{},1+\delta{})$，而$(0-\delta{},0+\delta{})$并不在$(0,2\pi{}]$中，所以需要将$(0,2\pi{}]$的两端认同，即通过$\mathbb{R}/2\pi{}\mathbb{Z}$的方法。
 Prop $[x]=[x+2n\pi{}]$，记作等价关系$x\sim{}x+2n\pi{}$。
 Lemma 如果$\tilde{f}_{n}:\mathbb{R}\rightarrow{}\mathbb{C}$满足$\tilde{f}_{n}(x)=\tilde{f}_{n}(x+2\pi{})-2\pi{}n$，$x_{0}\sim{}y_{0}$，则$\tilde{f}_{n}(x_{0})=\tilde{f}_{n}(y_{0})+2\pi{}mn$。
 Prove 
$$
\begin{eqnarray}
&=&\tilde{f}_{n}(x_{0})-\tilde{f}_{n}(y_{0})\\
&=&\tilde{f}_{n}(x_{0})-\tilde{f}_{n}(x_{0}-2\pi{}m)\\
&=&m2\pi{}n
\end{eqnarray}
$$
 Def 若$f_{n}(0)$等于$0$，定义$f:S^{ 1}\rightarrow{}S^{1},p\circ{}[x]\mapsto{}p\circ{}\tilde{f}_{n}(x)$。
 Thm $\{f\in{}\mathscr{F}(S^{1},S^{1})|f(1)=1\}$和$\{\tilde{f}_{n}\}$一一对应。
 Prove 
给一个$\tilde{f}_{n}$能确定唯一的$f$，若给一个$f$有两个函数$\tilde{f}_{n}$和$\tilde{g}_{m}$与其对应，则
$$
\begin{eqnarray}
e^{i\tilde{f}_{n}(x)}&=&e^{i\tilde{g}_{m}(x)}\\
\tilde{f}_{n}(x)&=&\tilde{g}_{m}(x)+2k\pi{}\\
\end{eqnarray}
$$
由于$\tilde{f}_{n}(0)=\tilde{g}_{n}(0)=0$，所以$k=0$，即$\tilde{f}_{n}=\tilde{g}_{m}$。
然后证明给一个$f$就有一个对应的$\tilde{f}_{n}$。
设$f(e^{i[x]})=e^{i[y(x)]}$定义$\tilde{f}_{y}(x)=y(x)+2k\pi{}$，由$y(0)+2k\pi{}=0$可定下唯一的$k$（其实就是给$[y]$取了规范固定）。显然由此得到的$\tilde{f}_{y}=\tilde{f}_{y+2m\pi{}}$，所以定义是良好的。
 Def 称$n$是函数$\tilde{f}_{n}$和对应的$f$的度，记作$deg(f)$
 Lemma 
1. $deg(f)=deg(g)\leftrightarrow{}f$同伦于$g$
2. $\forall{}n\in{}\mathbb{Z}$，都有对应的度为$n$的函数。
 Thm $S^{1}$的基本群同构于$\mathbb{Z}$
 Prove 
由于$S^{1}$是弧连通的，所以基本群与基点选择无关。
 Thm 设$X,Y$是弧连通的拓扑空间，则$\pi{}_{1}(X\times{}Y,(x_{0},y_{0})\simeq{}\pi{}_{1}(X,x_{0})\oplus{}\pi{}_{1}(Y,y_{0})$。
### 单纯复形的边群
 Def 定义单纯复形$K$的边道路为$|K|$的一个点列$v_{0}v_{1}...v_{k}$，满足$v_{i}v_{i+1}$是一个$0-$或者$1-$单形，如果序列起点和终点是同一个点，则称这个边道路为$v_{0}$处的一个边圈。
 Def 称单纯复形$K$的两个边圈$\alpha{},\beta{}$是等价的，如果$\alpha{}$经过有限次下列两种操作可以得到$\beta{}$
1. 如果$v_{i-1}v_{i}v_{i+1}$可以展开$K$的一个$2-$单形，则可以用$v_{i-1}v_{i+1}$与之互相替代（有可能中间是个洞？）
2. 如果$v_{i-1}=v_{i+1}$，则闭合边道路$v_{i-1}v_{i}v_{i+1}$可以和$v_{i-1}$ 互相替代。
 Def 将顶点$v$处的边圈的等价类$[\alpha{}]$记作$\{vv_{\alpha{}1}...v\}$，并定义等价类之间的乘法运算$[\alpha{}]*[\beta{}]:=\{vv_{\alpha{}1}...vv_{\beta{}1}...v\}$。
 Thm 上面定义构成一个以$\{v\}$为单位元的群，称为$K$在$v$处的边群，记作$E(K;v)$。
 Thm $E(K;v)\simeq{}\pi{}_{1}(|K|;v)$
 Def 称一个多面体为弧连通且单连通的一维（最大单形的维数）单纯复形为一个树。
 Def 称树$T_{M}$是单纯复形$K$的一个最大树，如果它是$K$的一个单纯子复形且它的多面体不是$K$的其它是树的单纯子复形多面体的正规子集。
 Lemma 最大数包括单纯复形的所有$0-$单形。
 Def 给单纯复形$K$中的$1-$单形$\langle v_{i}v_{j}\rangle$分配“元素”$g_{ij}$，并用它们生成群$G(K;L)$，要求群乘法满足下列条件
3. 如果$\langle v_{i}v_{j}\rangle\in{}L$，则$g_{ij}=1$
4. 如果$\langle v_{i}v_{j}v_{k}\rangle$是$K$中的一个$2-$复形，则$g_{ij}g_{jk}g_{ki}=1$
 Thm $G(K;L)\simeq{}E(K;v)\simeq{}\pi{}_{1}(|K|;v)$。
 Thm 设$K$是一个连通单纯复形，则$H_{1}(K)\simeq{}\pi{}_{1}(|K|)/F$，其中$F$是$\pi{}_{1}(|K|)$的交换子群，定义为$\{x_{i}x_{j}x_{i}^{-1}x_{j}^{-1}|x_{i},x_{j} \in{}\pi{}_{1}(|K|)\}$。
 Cor 设$X$是一个连通拓扑空间，则$\pi{}_{1}(X)\simeq{}H_{1}(x)\leftrightarrow{}\pi{}_{1}(X)$是阿贝尔群。特别的，如果$\pi{}_{1}(X)$只有一个生成元，则$\pi{}_{1}(X)\simeq{}H_{1}(X)$。
 Cor 如果$X$和$Y$有相同的拓扑类型，则$H_{1}(X)\simeq{}H_{1}(Y)$。
